# Month 2 demo script

1. In the dashboard, use **Analyze page** for `https://example.com`. Show the
   semantic summary and navigation graph.
2. Run `Open https://example.com and click More information`. Show the plan,
   timeline, and final screenshot.
3. Run an authorized session task with a Session ID, then use the same Session
   ID and request a follow-up action without a URL. Show resumed navigation.
4. For a login or upload plan, use **Plan only**, then enable **Approve
   sensitive action** before execution.
