Project AURA v0.1 – Browser Intelligence Core

Month 1 Engineering Blueprint (Final)

Product Vision

AURA is an Enterprise Browser Intelligence Platform that teaches AI to understand and operate arbitrary websites like a human. It is not an IRCTC bot, SAP bot or Salesforce bot. Those become demonstrations of the same underlying platform.

Goal: Build the reusable foundation that can later power browser automation, self-healing navigation, multi-agent workflows and enterprise automation.

Problem Statement

Current browser automation frameworks require website-specific scripts with hardcoded selectors and navigation logic. Every UI change introduces maintenance work.

AURA replaces website-specific automation with:

  • Natural language task understanding
  • Reusable browser skills
  • Planning before execution
  • Website memory
  • Execution history
  • AI-ready architecture

Core Browser Skills (Reusable)

Instead of creating website adapters, AURA provides reusable browser skills that work across different websites.

SkillDescription
FindLoginFormLocate authentication forms.
FillInputFill text fields intelligently.
ClickElementClick buttons, links or menus.
SelectDropdownSelect values from dropdowns.
NavigateMenuTraverse hierarchical menus.
FindSearchBarLocate search interfaces.
ExtractTableRead structured table data.
DownloadFileHandle browser downloads.
UploadFileUpload documents.
CaptureScreenshotCreate execution evidence.
WaitForDownloadSynchronize downloads.
HandlePopupDismiss dialogs and alerts.

Month 1 Demo

The user types:

Open https://example-portal.com, login, navigate to Reports and download the latest PDF.

AURA will:

  1. Understand the request.
  2. Generate an execution plan.
  3. Launch Playwright.
  4. Use generic Browser Skills (not website-specific code).
  5. Navigate through the website.
  6. Download the document.
  7. Capture screenshots.
  8. Return execution logs and artifacts.

The same engine should work on multiple websites without creating dedicated adapters.
